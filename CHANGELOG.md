# Changelog

## 1.0.0 — 2026-09-01

- First public reproducibility release accompanying the manuscript.
- Included the production solver, tests, deterministic generators, raw data,
  summaries, plots, environment record, and validation metadata.
- Added release-integrity checks and SHA-256 hashes for all distributed files.

## 0.2.0 — 2026-08-29

- Added automatic block decomposition and target-class recognition.
- Added the six-state global dynamic program with witness reconstruction.
- Added explicit cycle and complete-multipartite local signatures.
- Added disconnected, isolated-vertex, signed-weight, and vertex-cost support.
- Added portable JSON, edge-list, and graph6 command-line inputs.
- Added definition-level, fast independent, and exhaustive reference solvers.
- Added graph-atlas audits, random cross-checks, exhaustive small-instance
  baselines, and fresh-process weighted and unweighted scale benchmarks.
